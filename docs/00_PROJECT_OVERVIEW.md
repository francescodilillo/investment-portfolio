# Project Overview

## Objective

Build a professional-grade investment dashboard that provides significantly more insight than a broker interface.

The dashboard should answer questions like:

- How much richer am I today?
- Where did my returns come from?
- How much came from investing?
- How much came from employer equity?
- Am I outperforming the market?
- Am I on track for Financial Independence?
- How diversified am I?
- What is my Box 3 position?

## Design principles

- Fast
- Interactive
- Beautiful
- Accurate
- Fully deterministic
- Generated entirely from transaction history

No manual calculations should exist inside the application.
