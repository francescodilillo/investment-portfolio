# Data Model

Transactions are the single source of truth.

Required fields

- Date
- Instrument
- Buy / Sell
- Quantity
- Price
- Currency
- Broker
- Fees

Derived entities

## Holdings

Current open positions.

## Closed Positions

Fully exited investments.

## Cash Flows

External contributions

External withdrawals

## Employer Equity

RSU grants

## Monthly Snapshots
